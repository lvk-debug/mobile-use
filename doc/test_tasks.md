# mobile-use 测试任务集

按难度和能力维度分类，用于系统性测试 Agent 的各项能力。

---

## 使用方式

```python
from mobile_use.agent import Agent
from mobile_use.agent.views import AgentConfig

config = AgentConfig(
    task="打开设置，找到关于手机，告诉我 Android 版本号",
    use_vision=True,
    include_xml=False,
    max_steps=20,
)
agent = Agent(config=config, device=device, llm=llm)
result = await agent.run()
print(result.final_answer)
```
